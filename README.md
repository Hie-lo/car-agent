# Vehicle Radar Agent — Blueprint Package

This package contains the implementation brief intended to be given to a coding agent.

- **`AGENTS.md`** — source of truth for current release scope, architecture, source-access policy, matching/pricing rules, Telegram UX, subscription logic, security, milestones, and acceptance tests.
- **`update.md`** — future roadmap only. In particular, the standalone website/dashboard is deliberately excluded from the current release.

## How to use

1. Put these files at the project root.
2. Give the coding agent the repository and tell it to read `AGENTS.md` completely before making changes.
3. Start with Milestone 0 in `AGENTS.md`: prove the actual permitted data access and API limits before building continuous monitoring.
4. Do not implement `update.md` items until explicitly requested.

The documents are design/implementation instructions, not proof that external API credentials, commercial permissions, price-provider quality, or source quotas have already been obtained. Those must be verified with real responses and current provider terms.
